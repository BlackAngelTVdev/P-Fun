## 1. Introduction

### 1.1 Objectifs du projet

#### Objectifs produit
Le programme doit afficher une ou plusieurs séries de données locales concernant la cryptomonnaie, afin de pouvoir comparer les différentes courbes dans le temps.



#### Objectifs pédagogiques

Mettre en œuvre les principes de programmation fonctionnelle étudiés durant le cours de 323 et approfondir les connaissances en C#.


### 1.2 Description du domaine

#### Le domaine d'application
Le domaine choisi est la cryptomonnaie et la finance de manière générale.


#### Les sources de données
Les sources de données utilisées durant le projet sont principalement Binance, au travers de leur API.
